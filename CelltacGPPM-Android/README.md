# Celltac G PPM Android

Android WebView app wrapping the current Celltac G PPM site.

## Features
- Uses the live GitHub Pages site and existing Supabase backend.
- Keeps login, manager/engineer roles, visits, spare parts and reports.
- Android file chooser is restricted to images.
- Back button navigates within the site.
- External links open in the browser.

## Build
The repository includes a GitHub Actions workflow that builds a debug APK automatically.
